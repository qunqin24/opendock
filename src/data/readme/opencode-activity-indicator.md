# OpenCode plugins

## Plugins

- [`opencode-figma`](figma): Figma files and annotations in a session's side panel.
- [`opencode-pull-requests`](github): GitHub pull request panel, composer pill, and pull request browser.
- [`opencode-activity-indicator`](activity-indicator): macOS menu bar session status and Dock badges for pending input prompts.
- [`opencode-jira`](jira): The Jira ticket of a session's branch in the side panel.
- [`opencode-copilot-websearch`](copilot-websearch): Web search backend powered by GitHub Copilot's hosted MCP web search.
