# opencode-beads_rust-stats-sidebar

Плагин для OpenCode V2, который показывает статистику [beads_rust](https://github.com/Dicklesworthstone/beads_rust) и активные задачи в боковой панели терминального интерфейса.

## Что отображается

- Общее количество задач.
- Количество открытых задач, задач в работе, заблокированных и закрытых задач.
- Полоска из 10 символов и процент от общего количества для каждой категории.
- ID и название задачи со статусом `in_progress`.
- Строка `2 epics ready to close` (для русской локали `2 эпика готовы к закрытию`), если есть эпики, у которых все дочерние задачи закрыты. Строка появляется только при положительном количестве таких эпиков и располагается после статистики и перед активными задачами.
- Описание по запросу, если активная задача только одна.
- Список `ID - название`, если активных задач несколько.

Пример с одной активной задачей:

```text
Beads
Всего задач: 18
Открыто     ■■■■■■□□□□ 11 (61%)
В работе    ■□□□□□□□□□  1 (6%)
Блокировано ■■■■■□□□□□ 10 (56%)
Закрыто     ■■■□□□□□□□  6 (33%)

opencode-mjf ▾
Название текущей задачи
```

Пример с несколькими активными задачами:

```text
Beads
Всего задач: 4
Открыто     ■■■□□□□□□□ 1 (25%)
В работе    ■■■■■□□□□□ 2 (50%)
Блокировано ■■■□□□□□□□ 1 (25%)
Закрыто     ■■■□□□□□□□ 1 (25%)

opencode-bb7 - Временная задача 4
opencode-mjf - Временная задача 2
```

Если активных задач нет, список задач не отображается. Строка готовых к закрытию эпиков показывается независимо от наличия активных задач.

## Как это работает

Серверная часть плагина выполняет три команды в каталоге текущего проекта:

```sh
br stats --json --no-activity
br list --status in_progress --json
br epic status --eligible-only --json
```

Из `stats` берутся общее количество и статистика статусов. Из `list` берутся задачи `in_progress`, отсортированные по `updated_at` от более новых к более старым. Из `epic status --eligible-only` берётся количество эпиков, у которых все дочерние задачи закрыты. Все три команды выполняются параллельно при загрузке плагина, затем через 5 секунд после завершения каждого запроса.

TUI-часть передаёт в RPC location текущего проекта, поэтому статистика не смешивается с другими открытыми проектами. До первого успешного ответа блок скрыт. Во время последующих обновлений отображаются последние полученные данные.

Если активная задача одна, клик левой кнопкой мыши по ID или названию раскрывает и скрывает описание:

- `▾`: описание закрыто;
- `▴`: описание открыто.

Состояние раскрытия сохраняется для последней раскрытой задачи, пока плагин загружен.

Если активных задач несколько, они выводятся списком `ID - название`. В этом случае стрелки, описания и обработчики клика отсутствуют.

Если Beads не инициализирован, `br` недоступен или чтение данных `stats`/`list` завершилось ошибкой, плагин скрывает весь блок. Если команда `br epic status --eligible-only --json` недоступна или вернула некорректный ответ, статистика и активные задачи сохраняются, а строка про эпики просто не показывается.

## Установка и обновление

Для работы нужны:

- OpenCode V2 с поддержкой `sidebar.content`;
- команда `br`, доступная в `PATH` серверного процесса OpenCode;
- инициализированный каталог `.beads` в проекте.

Установить плагин глобально через CLI OpenCode V2 можно из npm или напрямую из GitHub:

```sh
opencode plugin add opencode-beads_rust-stats-sidebar
```

```sh
opencode plugin add github:melik/opencode-beads_rust-stats-sidebar
```

Либо подключить его декларативно в `opencode.jsonc` (глобально в `~/.config/opencode/opencode.jsonc`, либо в проекте в `opencode.jsonc` или `.opencode/opencode.jsonc`):

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": ["opencode-beads_rust-stats-sidebar"]
}
```

Плагин состоит из серверной, TUI и RPC частей, поэтому одной записи в `opencode.jsonc` достаточно для автоматической загрузки всех частей (отдельная настройка `cli.json` не нужна). В sidebar он всегда сохраняет короткий заголовок `Beads`.

Для локальной установки поместите каталог плагина в `~/.config/opencode/plugins/opencode-beads_rust-stats-sidebar` или `.opencode/plugins/opencode-beads_rust-stats-sidebar` (он загрузится автоматически), либо укажите локальный путь к каталогу в массиве `plugins`.

Обновление установленного плагина:

```sh
opencode plugin update opencode-beads_rust-stats-sidebar
```

Изменения конфигурации и файлов плагина подхватываются OpenCode через механизм перезагрузки. Полного перезапуска обычно не требуется.

## Локализация и оформление

Русская системная локаль включает русские подписи. Для всех остальных локалей используется английский. Выбор учитывает `LC_ALL`, `LC_MESSAGES`, `LANG` и системную локаль `Intl`.

Названия и описания задач не переводятся. Заголовок `Beads` выделен жирным основным цветом темы, остальные строки используют приглушённый цвет темы.

## Ограничения

- Описание доступно только при одной активной задаче; список из нескольких задач его не поддерживает.
- Поддерживается выбор текущей задачи через её статус; привязки к конкретной сессии OpenCode или исполнителю нет.
- Плагин только читает данные: создание, закрытие и изменение задач через sidebar не поддерживаются.
- Для описания одиночной задачи используется мышь; отдельной клавиатурной команды для его раскрытия нет. Поддержка мыши зависит от терминала.
- Обновление выполняется опросом через 5 секунд после завершения предыдущего запроса, а не подпиской на события Beads.
- Активность из Git, среднее время выполнения и дополнительные разбивки `br stats` не отображаются.
- Полоски и проценты округляются до целых. При небольшом количестве задач одна задача может заполнить несколько символов.
- Заблокированные задачи могут учитываться и в других статусах. Поэтому строки и проценты не являются взаимоисключающими и могут суммарно превышать 100%.
- При нулевом общем количестве задач полоски пустые, проценты равны нулю.

## Структура

- `index.ts`: регистрация серверного RPC.
- `beads.ts`: запуск `br`, проверка и преобразование данных.
- `rpc.ts`: схема обмена между сервером и TUI.
- `tui.tsx`: блок sidebar, обновления и раскрытие описания.
- `display.ts`: полоски, числа и проценты.
- `i18n.ts`: системная локаль и подписи.
