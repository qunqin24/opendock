# opencode-beads_rust-stats-sidebar

[![npm version](https://img.shields.io/npm/v/opencode-beads_rust-stats-sidebar)](https://www.npmjs.com/package/opencode-beads_rust-stats-sidebar)

Плагин для OpenCode V2, который показывает статистику [beads_rust](https://github.com/Dicklesworthstone/beads_rust) и текущую задачу, либо эпик, к которому она относится, в боковой панели терминального интерфейса.

## Что отображается

- Общее количество задач.
- Количество открытых задач, задач в работе, заблокированных и закрытых задач.
- Полоска из 10 символов и процент от общего количества для каждой категории.
- Строка `Epics ready to close: 2` (для русской локали `Эпики готовые к закрытию: 2`), если есть эпики, у которых все дочерние задачи закрыты. Строка появляется только при положительном количестве таких эпиков и располагается после статистики.
- Ровно один блок текущей задачи ниже статистики. Текущая задача — самая свежая задача в работе, а если задач в работе нет — самая свежая закрытая задача.
- Если текущая задача относится к открытому эпику, блок показывает этот эпик: строку сводки `▼ <id-эпика> <процент>% (<готово>/<всего>)` и его дочерние задачи.
- Иначе текущая задача показывается одной строкой: `[✓] Название` для закрытой задачи или `[◐] Название` для задачи в работе.
- Глиф статуса перед каждой задачей: `✓` закрыта, `◐` в работе, `○` готова, `●` заблокирована, `❄` отложена. Блокировка выводится косвенно: открытая дочерняя задача эпика, отсутствующая в `br ready --json`, считается заблокированной.

Пример: задачи в эпике

```text
Beads
Всего задач: 8
Открыто     ■■■■■□□□□□ 4 (50%)
В работе    ■■■□□□□□□□ 2 (25%)
Блокировано ■■■□□□□□□□ 2 (25%)
Закрыто     ■□□□□□□□□□ 1 (13%)

▼ opencode-e2-auth-5u3 20% (1/5)
[✓] End-to-end authentication flow
[○] Public access and revocation
[◐] Comment moderation
[●] Rate limits and concurrency
[❄] Deferred email notifications
```

Пример: одна текущая задача

```text
Beads
Всего задач: 8
Открыто     ■■■■■□□□□□ 4 (50%)
В работе    ■■■□□□□□□□ 2 (25%)
Блокировано ■■■□□□□□□□ 2 (25%)
Закрыто     ■□□□□□□□□□ 1 (13%)

[◐] Fix retry loop
```

## Как это работает

Серверная часть плагина выполняет пять команд только для чтения в каталоге текущего проекта:

```sh
br stats --json --no-activity
br epic status --json
br ready --json
br list --status in_progress --json
br list --status closed --json
```

Из `stats` берутся общее количество и статистика статусов. Количество эпиков, готовых к закрытию, вычисляется по флагам `eligible_for_close` из `epic status --json`, поэтому список эпиков и счётчик используют один источник. Все пять команд выполняются параллельно при загрузке плагина, затем через 5 секунд после завершения каждого запроса.

Затем плагин выбирает одну текущую задачу: самую свежую задачу из `br list --status in_progress --json` или, если этот список пуст, самую свежую задачу из `br list --status closed --json`. Задача в работе всегда имеет приоритет. Файл `.beads/last-touched` больше не читается.

Родителя текущей задачи плагин определяет запросом `br show <id-задачи> --json`, поскольку `br list --json` не возвращает поле `parent`. Если полученный `parent` совпадает с одним из открытых эпиков из `br epic status --json`, плагин выполняет `br show <id-эпика> --json` и показывает этот эпик с дочерними задачами. Для эпика `done` считает закрытых детей, а `total` — всех детей с типом связи parent-child. Открытые дети, присутствующие в `br ready --json`, показываются как готовые, а отсутствующие в нём — как заблокированные.

Иначе текущая задача показывается одной строкой. Если нет ни задачи в работе, ни закрытой задачи, блок задач не отображается.

TUI-часть передаёт в RPC location текущего проекта, поэтому статистика не смешивается с другими открытыми проектами. До первого успешного ответа блок скрыт. Во время последующих обновлений отображаются последние полученные данные.

Если Beads не инициализирован, `br` недоступен или чтение данных `stats` завершилось ошибкой, плагин скрывает весь блок. Если любая команда или ответ для текущей задачи или её эпика завершилась ошибкой или вернула некорректные данные, статистика и строка про эпики сохраняются, а блок задач просто не показывается.

## Установка и обновление

Для работы нужны:

- OpenCode V2 с поддержкой `sidebar.content`;
- команда `br`, доступная в `PATH` серверного процесса OpenCode;
- инициализированный каталог `.beads` в проекте.

Установить плагин глобально через CLI OpenCode V2 можно из npm или напрямую из GitHub:

```sh
opencode plugin add opencode-beads_rust-stats-sidebar
```

```sh
opencode plugin add github:melik/opencode-beads_rust-stats-sidebar
```

Либо подключить его декларативно в `opencode.jsonc` (глобально в `~/.config/opencode/opencode.jsonc`, либо в проекте в `opencode.jsonc` или `.opencode/opencode.jsonc`):

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": ["opencode-beads_rust-stats-sidebar"]
}
```

Плагин состоит из серверной, TUI и RPC частей, поэтому одной записи в `opencode.jsonc` достаточно для автоматической загрузки всех частей (отдельная настройка `cli.json` не нужна). В sidebar он всегда сохраняет короткий заголовок `Beads`.

Для локальной установки поместите каталог плагина в `~/.config/opencode/plugins/opencode-beads_rust-stats-sidebar` или `.opencode/plugins/opencode-beads_rust-stats-sidebar` (он загрузится автоматически), либо укажите локальный путь к каталогу в массиве `plugins`.

Обновление установленного плагина:

```sh
opencode plugin update opencode-beads_rust-stats-sidebar
```

Изменения конфигурации и файлов плагина подхватываются OpenCode через механизм перезагрузки. Полного перезапуска обычно не требуется.

## Локализация и оформление

Русская системная локаль включает русские подписи. Для всех остальных локалей используется английский. Выбор учитывает `LC_ALL`, `LC_MESSAGES`, `LANG` и системную локаль `Intl`.

Заголовок `Beads` выделен жирным основным цветом темы. Все остальные строки, включая сводку эпика и строки задач, используют приглушённый цвет темы. Названия задач не переводятся.

## Ограничения

- Плагин только читает данные: создание, закрытие и изменение задач через sidebar не поддерживаются, обработчиков клика, диалогов и slash-команд нет.
- Текущая задача следует за самой свежей задачей в работе или самой свежей закрытой задачей; привязки к конкретной сессии OpenCode или исполнителю нет.
- Обновление выполняется опросом через 5 секунд после завершения предыдущего запроса, а не подпиской на события Beads.
- Активность из Git, среднее время выполнения и дополнительные разбивки `br stats` не отображаются.
- Полоски и проценты округляются до целых. При небольшом количестве задач одна задача может заполнить несколько символов.
- Заблокированные задачи могут учитываться и в других статусах. Поэтому строки и проценты не являются взаимоисключающими и могут суммарно превышать 100%.
- Блокировка дочерних задач в блоке эпика выводится косвенно: Beads хранит такие задачи как открытые, поэтому открытый ребёнок, отсутствующий в `br ready --json`, показывается как заблокированный.
- При нулевом общем количестве задач полоски пустые, проценты равны нулю.

## Структура

- `index.ts`: регистрация серверного RPC.
- `beads.ts`: запуск `br`, выбор текущей задачи, проверка и преобразование данных.
- `rpc.ts`: схема обмена между сервером и TUI.
- `tui.tsx`: блок sidebar и обновления.
- `display.ts`: полоски, числа, проценты и глифы задач.
- `i18n.ts`: системная локаль и подписи.
