# Groundbox integrations

Groundbox sandboxes inside the agent frameworks you already use. Each package plugs Groundbox
(fast, isolated Linux microVMs for agents: https://groundbox.dev) into one framework's own
sandbox or workspace interface. Set `GROUNDBOX_API_KEY` (create one at https://app.groundbox.dev/keys).
