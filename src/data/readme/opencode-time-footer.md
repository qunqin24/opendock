# OpenCode plugins

A Bun workspace for small OpenCode plugins.

- [opencode-time-footer](./timeline/README.md): appends a machine-local time footer to each completed text block, with an optional label.

Published on npm as [`opencode-time-footer`](https://www.npmjs.com/package/opencode-time-footer). See the plugin README for configuration, limitations, and development commands.
