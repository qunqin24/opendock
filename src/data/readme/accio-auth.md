# Accio for magpie

**Accio 订阅里已有的 Qwen、GLM、DeepSeek、MiniMax、Kimi，变成 magpie 里的一排模型 —— 装了 Accio 客户端就直接用它的登录态；没有就走客户端下载 + 网页授权。**

Accio（阿里 Accio Work）是一个把多家模型打包进订阅的客户端；这个插件把那部分订阅接进
magpie：任何支持 OpenAI 协议的 agent 都能选它的模型。
非官方插件，与阿里巴巴集团、Alibaba.com、Accio 官方没有任何隶属或背书关系。

```
模型       15 条兜底；登录后跟随平台目录
倍率       x0.013 ~ x2.8（同一订阅内跨度约 215 倍）
上下文     最高 1,000,000；最低 200,000
积分桶     每日 / 每月 / 推荐，三桶各一条进度条
登录       软件优先（有客户端直接导入，没有则下载）/ 干净窗口网页授权
```

## 功能

- **软件优先登录** —— 点「登录 Accio」先看本机 Accio 客户端：有登录态就直接导入（0 交互、不弹浏览器）；没有就打开客户端下载页，装好并在客户端里登录后**同一次点击**自动接上（最多等 10 分钟）。
- **另加「网页授权」这条** —— 用途是「添加另一个账号」或不想装客户端：由插件自己拉起一个独立 profile 的浏览器窗口（读不到你日常的登录态），登录完自动关闭；不会落到已经登录的号上。
- **邀请码** —— 独立登录方式「Accio 邀请码」：一个数字框（0/空=自动、1=保持、其它=新码），选完直接接登录，官方分享链接的 `?ic=` 参数自动带上。
- **一个供应商，两个站点** —— 中国站与国际站只在登录页不同；换码、目录、对话、额度同一个网关，所以不会出现两张各登一次的卡。
- **倍率标在模型上** —— 每条模型带 `x0.03` 这样的倍率胶囊，与计费同源；最便宜的档和最贵的档差约 215 倍。
- **积分算得准** —— 三桶积分各一条进度条；用完的桶显示 100%，不会被当成「还有额度」排到路由队首。
- **续期不打死账号** —— Accio 刷新会轮换 refresh_token，插件按凭据身份串行，不会出现「并发续期 → invalid_grant → 账号失效」。
- **工具能真正用起来** —— 上游的工具调用是分片到达的，插件合并成一次调用再交给 agent；并发多条工具结果时保持配对相邻。
- **风控页能识别** —— 上游偶尔回 HTTP 200 + 一张拦截页；插件按 content-type 判出来并带上服务端原文，而不是让 agent 看到「模型不回复」。
- **图片输入跟随厂商声明** —— 每个模型显式声明能否收图：能收的直接发内联图，不能收的不会被 magpie 误判成能收。
- **思考内容不污染正文** —— 上游用 `thought` 标记的片段映射到 `reasoning_content`。

## 签到

**没有每日签到。** Accio 的积分按套餐周期自动刷新（每日桶的刷新时刻从上游读），
所以签到钩子返回 `inactive`，magpie 不会给你挂一个永远失败的签到。

## 安装

在 magpie 的 **插件 → 发现** 搜 `Accio`，点**安装**。

> 卡片标题来自包内的 `name`（`Accio`），npm 上的包名是 `accio-auth` —— 这两个不一样是故意的，
> 发布脚本在发布时换名，装的人什么都不用做。

### 命令行

```bash
# 从仓库源码（装好之后卡片标题就是包内的 Accio）
magpie plugin add github:MYCF711/magpie-accio-auth

# 本地目录（改代码时）—— ⚠ 路径安装的卡片标题就是那个路径
magpie plugin add <WORKSPACE>\projects\magpie-accio-auth

# 从 npm（发布之后）
magpie plugin add accio-auth
```

装完确认：

```bash
magpie plugin list
# Accio  on
#   accio (Accio, 15 models)  signed in as …
```

### 登录

在 magpie 的供应商卡片上点 **登录 Accio** —— 它会先看本机 **Accio 客户端**里有没有登录态：

- **有登录态** → 直接读客户端凭据导入（不弹浏览器、不用再登一次）。首次用之前，在客户端里登录过一次即可。
- **装了但没登录** → 提示你打开客户端登录一次，登录完自动接上（最多等 10 分钟）。
- **没装** → 打开客户端下载页（`www.accio-ai.com/work`）。装好并在客户端里登录后，
  **同一次点击**会自动接上（最多等 10 分钟），不用回来再点一次。

要**添加另一个账号**、或者不想装客户端：用第二条 **「登录 Accio（网页授权，不装客户端）」**，
先选站点（中国站 / 国际站），再在弹出的窗口里完成阿里账号登录 —— 回调走本机 `127.0.0.1`。

⚠ 网页授权那个窗口是插件自己开的一个「干净窗口」（独立的一次性浏览器 profile，
读不到你日常浏览器的任何登录态），登录完自动关闭并删掉该 profile。
所以「添加另一个账号」时会老老实实让你重新登一次，**不会**默默落到已经登录的那个号上。
窗口中途关掉也没关系：会立刻提示「登录窗口已关闭」，重新点一次即可，不影响已有账号。

## 常见问题

**要装 Accio 的桌面客户端吗？** 装了最省事 —— 有客户端登录态就直接导入，一步都不用点。
不装也能用：选「登录 Accio（网页授权）」，那是标准的 OAuth + 本机回环回调。
网页登录窗口由插件自己拉起（Chrome / Chromium / Edge 等 Chromium 内核浏览器任选其一）；
本机一个都没有时会明确报错并列出找过的路径，**不会**偷偷改用你日常的浏览器 ——
那样会直接登进已有的号，看着像「添加账号没生效」。

**中国站和国际站是两张卡吗？** 不是。两站的区别只在登录页域名；换码、模型目录、对话、额度都走同一个网关，所以是一个供应商、两组登录态可以并存（同站两个账号也支持）。

**为什么卡片上不显示账号名？** Accio 的登录响应只给两个 token 和一个过期时间，不给账号名、邮箱或用户 id。插件不编造显示名，所以卡片显示「Accio」；多账号靠内部的 `uid` 区分。

**重复登录同一个账号会怎样？** 会多一张卡，而不是覆盖。原因同上：拿不到稳定的账号 id。删掉旧的那张即可（不会把可用凭据弄丢）。

**卡片突然显示「已退出登录」是怎么回事？** 只有一种情况会显示它：上游明确回了「这个 token 我不认」
（`401 NOT_LOGIN` / `403 auth failed`）。这通常意味着需要**重新登录一次**（点「登录 Accio」，
在新的干净窗口里登同一个号即可）。两种情况值得注意：

- 插件不会因为**网络抖动、超时、限流、5xx** 就把号标死 —— 这些错误只显示在卡片上；
- 「上游说不认这个 token」与「本机出口被阿里风控限流」的报文**逐字相同**，
  所以插件要求**连续两次（间隔 ≥1 分钟）**都报失效才标记账号。单次抖动不会动你的号。

**积分显示 0 就是没额度了吗？** 是。插件读的是账号真实的积分桶；用完的桶显示 100%，不会伪装成「还有余量」而把这个号排到路由队首。

**会不会因为共用登录态被风控？** 插件按官方客户端的请求形状发（`utdid` 装机 id、`appKey`、版本头），并把「HTTP 200 + HTML 拦截页」这种风控形态识别成明确错误。但任何非官方调用都有风险 —— 用它就意味着接受这一点。
