# session-bar

OpenCode TUI sidebar plugin — list all sessions with quick switch and delete.

<img width="338" height="939" alt="image" src="https://github.com/user-attachments/assets/b360a483-6bf2-4c8b-896c-8bfb966cb9c6" />


## Install

```bash
opencode plugin add session-bar
```

Or add to `tui.json`:

```json
{
  "plugin": ["session-bar"]
}
```
