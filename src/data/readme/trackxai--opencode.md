# trackxai plugins

Plugins that connect a coding agent to [trackxai](https://trackxai.kalebtec.com), an agent-native task tracker.
Version 0.1.0. MIT licensed. Release notes are in [CHANGELOG.md](CHANGELOG.md).

This repository is generated by the trackxai release pipeline. A change made here is overwritten by the next
release.

## Install

The Claude Code and Codex plugins install from this repository. Sign in with your browser: there is no token to
paste.

### Claude Code

In a terminal, run:

```
claude plugin marketplace add kalebteccom/trackxai-plugins
claude plugin install trackxai@trackxai
```

Then start Claude Code, run `/mcp`, pick `trackxai` and sign in with your browser. Inside a session, the same two steps
are `/plugin marketplace add kalebteccom/trackxai-plugins` and `/plugin install trackxai@trackxai`.

- Check: `claude mcp get plugin:trackxai:trackxai`
- Pin this release: `claude plugin marketplace add kalebteccom/trackxai-plugins#v0.1.0`
- Update: `claude plugin marketplace update trackxai`, then `claude plugin update trackxai@trackxai`
- Remove: `claude plugin uninstall trackxai@trackxai`, then `claude plugin marketplace remove trackxai`

### Codex

In a terminal, run:

```
codex plugin marketplace add kalebteccom/trackxai-plugins
codex plugin add trackxai@trackxai
codex mcp login trackxai
```

The last command opens your browser on trackxai.

- Check: `codex mcp list`
- Pin this release: `codex plugin marketplace add kalebteccom/trackxai-plugins --ref v0.1.0`
- Update: `codex plugin marketplace upgrade trackxai`, then `codex plugin remove trackxai@trackxai` and
  `codex plugin add trackxai@trackxai`
- Remove: `codex plugin remove trackxai@trackxai`, then `codex plugin marketplace remove trackxai`

### The other harnesses

OpenCode and Pi install from npm, and those packages are not published yet. Hermes Agent installs by copying files.

| Directory       | Harness                                              | Install                                                                                                     |
| --------------- | ---------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `opencode`      | OpenCode                                             | npm package `@trackxai/opencode`, not published yet                                                         |
| `pi`            | Pi                                                   | npm package `@trackxai/pi`, not published yet                                                               |
| `hermes`        | Hermes Agent                                         | Merge `mcp_servers.trackxai.yaml` into `config.yaml`, and copy `trackxai/` into the plugins directory       |
| `agent-plugins` | The `trackxai login` command and a helper for the above | npm package `@trackxai/agent-plugins`, not published yet                                                    |

## What is here

| Directory       | Holds                                                                                  |
| --------------- | -------------------------------------------------------------------------------------- |
| `claude-code`   | The Claude Code plugin, and its marketplace entry at `.claude-plugin/marketplace.json`  |
| `codex`         | The Codex plugin under `codex/trackxai`, and its entry at `.agents/plugins/marketplace.json` |
| `opencode`, `pi`, `hermes` | The OpenCode, Pi and Hermes Agent plugins                                |
| `agent-plugins` | The `trackxai login` command and the registration helper the Pi and OpenCode plugins import |

The Claude Code, Codex and OpenCode plugins name the trackxai server by URL and nothing else. The harness signs you
in through its own MCP OAuth, so no file here holds a token. Pi and Hermes take a token by reference, never as a
value. Sign-in steps, profile directories and uninstall steps are on the [trackxai setup page](https://trackxai.kalebtec.com/mcp-setup).
