# 鵜鶘巡檢

[English](https://github.com/fengcyborg/magpie-pelican-hour/blob/main/README.md) · [简体中文](https://github.com/fengcyborg/magpie-pelican-hour/blob/main/README.zh-CN.md) · [繁體中文](https://github.com/fengcyborg/magpie-pelican-hour/blob/main/README.zh-TW.md) · [日本語](https://github.com/fengcyborg/magpie-pelican-hour/blob/main/README.ja.md) · [Deutsch](https://github.com/fengcyborg/magpie-pelican-hour/blob/main/README.de.md)

鵜鶘巡檢會依序向 Magpie 官方 Codex 供應商下已啟用的訂閱帳號發出同一個提示詞，產生鵜鶘騎腳踏車的動畫。在 Magpie 側邊欄開啟「鵜鶘巡檢」，或前往[本機監測頁面](http://localhost:18765/)。選擇帳號即可查看下次檢測時間、最新作品和執行紀錄。

## 安裝

在 Magpie 的外掛程式頁面輸入套件名稱 `magpie-pelican-hour` 加入。使用 Magpie CLI 時，可執行以下指令。

```sh
magpie plugin add npm:magpie-pelican-hour
```

啟用外掛程式，讓 Magpie 保持執行並避免電腦進入睡眠。每次檢測都會使用該帳號的訂閱額度。使用帳號卡片上的開關即可暫停或恢復檢測。開啟時會要求執行一次檢測，關閉時則取消尚在等候的啟用檢測，既有紀錄仍會保留。

## 語言與使用說明

選擇「跟隨系統」後，每次巡檢開始時都會讀取執行 Magpie 的電腦的系統語言。也可在本機頁面右上角選擇簡體中文、繁體中文、英文、日文或德文。若系統語言不在支援範圍內，則使用簡體中文。外掛程式會直接送出該語言的提示詞，要求模型用相同語言撰寫回覆、標題、畫面文字和無障礙說明。在執行詳情中可核對當次送出的提示詞和模型原文。切換語言適用於後續巡檢。Magpie 的側邊欄和外掛程式詳情使用 Magpie 的介面語言。

## 排程與勿擾時段

預設每個帳號每小時檢測一次，時間隨機落在第 01 到 59 分鐘。持續執行時，下一小時的排定分鐘與上次開始時的分鐘最多相差 10 分鐘，兩次檢測約隔 50 至 70 分鐘。重新啟動後會沿用既有排程，睡眠期間錯過的時段會略過。外掛程式每小時更新帳號清單，並在發出請求前確認帳號狀態。新啟用的帳號會自動加入，已移除或停用的帳號仍保留歷史紀錄。

在「勿擾與休息日」開啟每日勿擾，選擇開始和結束時間，按「儲存設定」。設定對全部帳號生效，以執行 Magpie 的電腦所在時區為準，可跨越午夜。進入勿擾時段會暫停巡檢並中斷進行中的請求。若在此期間開啟帳號，第一次檢測會等到時段結束；期間再次關閉帳號即可取消。

## 地區行事曆與休息日抽樣

啟用休息日抽樣後，可設定每個帳號每天檢測 1 至 8 次。工作日和補班日維持約每小時一次。「均勻分布」會將勿擾時段以外的可用時間等分，為各帳號在每個區間各安排一次。「自選時刻」則可逐一指定時間。儲存後切換帳號，即可查看當天或下一個休息日的計畫。

在「休息日日曆」中，可依語言決定地區，也可自行指定，例如 en-GB 與 en-US 會使用不同的行事曆。逐月瀏覽並點選今天或未來的日期，即可切換為工作日或休息日。再點一次恢復地區預設，按「儲存設定」後套用到所有帳號。

次數依執行 Magpie 的電腦當地日期計算，排程檢測開始時即計一次。當天修改設定會計入已開始的檢測。服務忙碌時，等候最多一小時，遇到下一個時段、勿擾時段或午夜會提前結束。關機或睡眠期間錯過的舊時段會略過。手動啟用帳號時的檢測另外記錄。

行事曆可離線使用。中國大陸使用已公布的 2026、2027 年放假和補班安排。其他 245 個國家和地區使用 python-holidays 0.109 提供的 2026 至 2028 年公眾假期資料，可依公司或地方差異自行調整。未收錄的年份或地區按週末安排，頁面會提示。進入日光節約時間時會略過當天不存在的自選時刻，秋季回撥時重複的時刻只抽樣一次。[假期資料](https://github.com/vacanza/holidays) · [中國大陸 2026 年安排](https://www.beijing.gov.cn/cs/gncs/zcwj/202603/t20260327_4568275.html) · [2027 年安排](https://chinajob.mohrss.gov.cn/h5/c/2026-11-09/635850.shtml)

## 檢測、預覽與儲存位置

外掛程式透過 Magpie 的本機閘道指定帳號，以巡檢語言將固定任務傳送給 `gpt-6.2-astra`，推理強度為 `xhigh`，最多可同時檢測 3 個帳號。在執行詳情中可查看原始回覆、HTML、擷取的 SVG 和作品預覽。閱畢模型回覆後，可返回同一筆紀錄。完整 HTML 包在 JSON 字串內時會先解碼再擷取。

縮圖進入畫面時會播放動畫。沒有錄影檔時，圖庫會在隔離的縮圖中播放已儲存的 HTML 預覽，舊作品也適用。若找到 Chrome 或 Chromium 以及 FFmpeg，外掛程式會為含指令碼的作品錄製每秒 60 格的無聲影片，並為限制自動播放的瀏覽器儲存每秒 30 格的動畫 PNG。可透過 `CHROME_PATH` 和 `FFMPEG_PATH` 指定執行檔的位置。

監測頁使用連接埠 18765。區域網路中可連線至此連接埠的裝置能檢視帳號別名、執行紀錄和作品。設定在本機上變更，登入憑證由 Magpie 管理。macOS 的預設儲存位置是 `~/Library/Application Support/magpie-pelican/`；若已設定 `XDG_DATA_HOME`，則使用 `$XDG_DATA_HOME/magpie-pelican/`。備份或移轉時可複製整個資料夾，更改帳號別名後紀錄仍對應到原來的帳號識別碼。

若要從原始碼安裝，請將完整資料夾放在固定位置，在 Magpie 選取該資料夾，或在資料夾中執行以下指令。

```sh
/Applications/magpie.app/Contents/MacOS/magpie plugin add "$PWD"
```
