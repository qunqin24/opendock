# ペリカンモニター

[English](https://github.com/fengcyborg/magpie-pelican-hour/blob/main/README.md) · [简体中文](https://github.com/fengcyborg/magpie-pelican-hour/blob/main/README.zh-CN.md) · [繁體中文](https://github.com/fengcyborg/magpie-pelican-hour/blob/main/README.zh-TW.md) · [日本語](https://github.com/fengcyborg/magpie-pelican-hour/blob/main/README.ja.md) · [Deutsch](https://github.com/fengcyborg/magpie-pelican-hour/blob/main/README.de.md)

Magpie の公式 Codex プロバイダーで有効になっている各アカウントに、同じプロンプトで自転車に乗るペリカンのアニメーションを生成させます。Magpie のサイドバーで「ペリカンモニター」を開くか、[ローカルのダッシュボード](http://localhost:18765/)にアクセスしてください。アカウントを選ぶと、次のチェック時刻、最新の作品、実行履歴を確認できます。

## インストール

Magpie のプラグイン画面で `magpie-pelican-hour` を追加します。CLI を使う場合は次のコマンドを実行します。

```sh
magpie plugin add npm:magpie-pelican-hour
```

プラグインを有効にし、コンピューターがスリープしない状態で Magpie を起動しておきます。チェックのたびに各アカウントの契約枠を消費します。アカウントカードのスイッチをオンにすると初回チェックが始まります。オフにすると保留中の初回チェックは取り消され、履歴は残ります。

## 表示言語とガイド

「システムの言語」を選ぶと、チェックの開始時に Magpie を実行しているパソコンの言語を読み取ります。ローカルの画面右上で簡体字中国語、繁体字中国語、英語、日本語、ドイツ語を指定することもできます。未対応の言語では簡体字中国語を使います。選んだ言語のプロンプトを送信し、回答、作品名、画面上の文章、アクセシビリティ用の説明を同じ言語で書くようモデルに指示します。実行の詳細で、その回に送信したプロンプトと回答の原文を確認できます。言語の変更は次回のチェックから適用されます。Magpie のサイドバーとプラグイン詳細には Magpie の表示言語が使われます。

## 定期チェックと休止時間

通常は毎時01分から59分の間でアカウントごとに実行時刻を決めます。連続稼働時は前回の開始分との差を10分以内に収めるため、間隔はおおむね50～70分です。再起動後も予定を引き継ぎ、スリープ中に過ぎた時間のチェックはスキップします。毎時アカウント一覧を更新し、実行直前にも状態を確認します。新しく有効にしたアカウントは自動で加わり、無効または削除したアカウントの履歴も残ります。

「休止時間と休日」で「毎日の休止時間」をオンにし、開始と終了を選んで「設定を保存」を押します。設定は Magpie を実行しているコンピューターの現地時刻で全アカウントに適用され、日付をまたげます。休止時間に入ると実行中のリクエストを中断します。この間に有効にしたアカウントの初回チェックは休止時間の終了まで待機し、再度オフにすると取り消されます。

## 休日カレンダーとサンプリング

休日のサンプリングを有効にすると、1アカウントにつき1日1～8回のチェックを設定できます。平日と振替出勤日は通常どおり約1時間間隔です。「均等に分散」は休止時間を除いた時間を等分し、区間ごとに各アカウントの時刻を選びます。「時刻を指定」では希望の時刻を選べます。保存後にアカウントを選ぶと、当日または次の休日の予定が表示されます。

「休日カレンダー」で言語の地域に従うか、地域を指定します。例えば en-GB と en-US は別のカレンダーを使います。月を切り替え、当日または将来の日付を押すと勤務日と休日が切り替わります。もう一度押すと地域の設定に戻ります。「設定を保存」を押すと全アカウントに反映されます。

日ごとの回数には現地の日付を使い、定期チェックが始まった時点で1回と数えます。設定変更前に開始した分も含みます。混雑時の待機は最長1時間で、次の枠、休止時間、日付の切り替わりで終了します。スリープや電源オフで過ぎた枠は後からまとめて実行しません。再開時の初回チェックは別に記録します。

カレンダーはオフラインで利用できます。中国本土は2026年と2027年の公表済み休日・振替出勤日、ほかの245か国・地域は python-holidays 0.109 の2026～2028年の祝日データを使います。地域や職場ごとの違いは日付を指定して調整できます。対象外の年や地域では週末ルールが適用され、画面に表示されます。夏時間への移行で存在しない指定時刻はその日だけスキップし、時計を戻して重なる時刻は1回だけ実行します。[祝日データ](https://github.com/vacanza/holidays) · [中国の2026年の予定](https://www.beijing.gov.cn/cs/gncs/zcwj/202603/t20260327_4568275.html) · [2027年の予定](https://chinajob.mohrss.gov.cn/h5/c/2026-11-09/635850.shtml)

## チェックと作品の保存

アカウントを選んで「今すぐ1回チェック」を押すと、定期チェックの一時停止中でも単発のリクエストを送れます。利用枠を消費し、休止時間と同時実行数の制限に従います。定期予定は維持され、手動チェックが完了するまでは重複した依頼をまとめます。再起動やスリープ中に過ぎた予定はスキップします。

履歴はアカウントと状態別に1ページ12件で表示し、詳細で実際のプロンプトを確認できます。モデルリクエストと作品保存の成功率は、各段階で結果が判明したものを集計します。中断や結果不明の過去の記録は対応する分母から除きます。意図的な中断には休止時間とプラグインの明示的な停止を含みます。破損した記録はファイルを残し、相対パスを画面に表示します。

Magpie のローカルゲートウェイがアカウントを指定し、チェックの言語で定型のプロンプトを推論強度 `xhigh` の `gpt-6.2-astra` に送ります。最大3アカウントが同時に実行できます。履歴の詳細ではモデルの回答、元の HTML、抽出した SVG、プレビューを確認できます。回答を開いた後は「実行の詳細に戻る」で元の画面に戻れます。JSON 文字列に包まれた完全な HTML 文書にも対応します。

サムネイルは画面に入ると再生されます。録画がない場合は、過去の作品も含め、保存済みの HTML プレビューをサンドボックス内で再生します。Chrome または Chromium と FFmpeg が見つかると、スクリプトを含む作品を 60 fps の無音動画として録画し、自動再生が制限されるブラウザー向けに 30 fps のアニメーション PNG も保存します。実行ファイルの場所は `CHROME_PATH` と `FFMPEG_PATH` で指定できます。

ダッシュボードのポートは18765です。このポートに到達できる LAN 上の端末は、アカウントの別名、履歴、作品を閲覧できます。設定はホスト上で変更します。ログイン情報は Magpie が管理します。macOS の保存先は `~/Library/Application Support/magpie-pelican/`、`XDG_DATA_HOME` を設定している場合は `$XDG_DATA_HOME/magpie-pelican/` です。バックアップや移行ではディレクトリ全体をコピーします。アカウントを改名しても履歴は同じ ID に紐付きます。

ソースから導入する場合はフォルダー全体を固定の場所に置き、Magpie で選択するか、そのフォルダーで次を実行します。

```sh
/Applications/magpie.app/Contents/MacOS/magpie plugin add "$PWD"
```
