# opencode-session-motion

[English](README.md)

给 OpenCode 桌面版的输入框加一条随会话状态变化的动画边框。八种动效、可调色板、彩色循环、阴影和完整的设置页。

## 功能

- 跟随会话状态：空闲 / 运行中 / 等待 / 完成 / 出错
- 八种边框效果：流动、彩虹、呼吸光晕、虚线行进、扫描线、彗星拖尾、霓虹闪烁、扩散波纹
- 颜色：每个状态单独取色，支持“彩色”模式沿自定义色板循环
- 色板：默认、霓虹、日落、冰蓝、森林、糖果，也可自定义
- 阴影：开关、大小、浓度、是否跟随边框颜色
- 强度、粗细、速度、方向都可调
- 设置保存在窗口本地；支持 `prefers-reduced-motion`
- `/motion-preview` 命令可预览任意状态

## 安装

```bash
opencode plugin add opencode-session-motion
```

或手动写入全局 `~/.config/opencode/opencode.json(c)`：

```jsonc
{
  "plugins": ["opencode-session-motion"]
}
```

安装后打开 **设置 → 输入框动效**，或按 `Ctrl+K` 搜索“输入框” / `motion`。

## 状态

| 状态 | 触发 |
| --- | --- |
| idle | 没有任务在跑 |
| working | `session.status` 为 busy |
| waiting | 等待权限确认、提问弹窗或重试 |
| done | 一轮完成，短暂庆祝 |
| error | 执行失败或被中断 |

## 效果

- **流动**：一段渐变沿边框绕行。
- **彩虹**：整圈多色渐变旋转。
- **呼吸光晕**：从无色渐入到满色，再退回无色，带内发光。
- **虚线行进**：虚线沿边框移动。
- **扫描线**：一个亮点拖着很短的尾迹扫过。
- **彗星拖尾**：亮点带一条长渐隐尾巴。
- **霓虹闪烁**：实线加发光，不规则闪烁。
- **扩散波纹**：从输入框边缘向外扩散的圆角波纹。

所有效果共用状态颜色、速度、粗细和强度设置。

## 设置

| 设置 | 可选值 |
| --- | --- |
| 启用边框 | 开 / 关 |
| 空闲时也流动 | 开 / 关 |
| 速度 | 慢 / 正常 / 快 |
| 顺时针 | 开 / 关 |
| 效果 | 流动 / 彩虹 / 呼吸光晕 / 虚线 / 扫描 / 彗星 / 霓虹 / 波纹 |
| 粗细 | 细 / 正常 / 粗（1–3px） |
| 强度 | 柔和 / 正常 / 强烈 |
| 阴影 | 开关、大小、浓度、跟随边框颜色、阴影颜色 |
| 颜色 | 运行中 / 等待 / 完成 / 出错，取色器选择 |
| 彩色 | 沿自定义色板循环 |
| 色环速度 | 慢 / 正常 / 快 |
| 色板预设 | 自定义 / 默认 / 霓虹 / 日落 / 冰蓝 / 森林 / 糖果 |
| 自定义色板 | 逗号分隔的 CSS 颜色 |

## 预览状态

想直接看某个状态的效果，在输入框执行：

```
/motion-preview waiting
/motion-preview done
/motion-preview error
```

也支持 `working` / `idle`。每个状态保持 5 秒，然后回到真实状态。

## 注意

- 仅支持 OpenCode 桌面版 / Web 窗口（GUI part），TUI 不显示。
- 需要 OpenCode 2.2 或更高版本。
- 插件通过 `contenteditable` 定位输入框容器，依赖宿主 DOM 结构；OpenCode 大版本升级后可能需要更新选择器。
- 关闭“阴影”后，所有效果都不会附带插件添加的发光或投影。
