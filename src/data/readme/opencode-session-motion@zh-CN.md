# opencode-session-motion

[English](README.md)

给 OpenCode 桌面版的输入框加一条随会话状态变化的动画边框。七种动效、可调色板、彩色循环、阴影和完整的设置页。

## 功能

- 跟随会话状态：空闲 / 运行中 / 等待 / 完成 / 出错
- 七种边框效果：流动、彩虹、呼吸光晕、虚线行进、扫描线、彗星拖尾、霓虹闪烁
- 颜色：每个状态单独取色，支持“彩色”模式沿自定义色板循环
- 色板：默认、霓虹、日落、冰蓝、森林、糖果，也可自定义
- 阴影：开关、大小、浓度、是否跟随边框颜色
- 强度、粗细、速度、方向都可调
- 可选：随 tok/s 变色，内置四套色带：冷色（默认）、速度表、全光谱、蓝紫粉
- 针对分块输出做了平滑：停顿 2.5 秒内保持上一次颜色，之后缓慢回落
- 设置保存在窗口本地；支持 `prefers-reduced-motion`
- `/motion-preview` 命令可预览任意状态

## 安装

```bash
opencode plugin add opencode-session-motion
```

或手动写入全局 `~/.config/opencode/opencode.json(c)`：

```jsonc
{
  "plugins": ["opencode-session-motion"]
}
```

安装后打开 **设置 → 输入框动效**，或按 `Ctrl+K` 搜索“输入框” / `motion`。

## 状态

| 状态 | 触发 |
| --- | --- |
| idle | 没有任务在跑 |
| working | `session.status` 为 busy |
| waiting | 等待权限确认、提问弹窗或重试 |
| done | 一轮完成，短暂庆祝 |
| error | 执行失败或被中断 |

## 效果

- **流动**：一段渐变沿边框绕行。
- **彩虹**：整圈多色渐变旋转。
- **呼吸光晕**：在较暗和满色之间循环呼吸，带内发光。
- **虚线行进**：虚线沿边框移动。
- **扫描线**：一个亮点拖着很短的尾迹扫过。
- **彗星拖尾**：亮点带一条长渐隐尾巴。
- **霓虹闪烁**：实线加发光，不规则闪烁。

所有效果共用状态颜色、速度、粗细和强度设置。

## 设置

| 设置 | 可选值 |
| --- | --- |
| 启用边框 | 开 / 关 |
| 空闲时也流动 | 开 / 关 |
| 速度 | 慢 / 正常 / 快 |
| 顺时针 | 开 / 关 |
| 效果 | 流动 / 彩虹 / 呼吸光晕 / 虚线 / 扫描 / 彗星 / 霓虹 |
| 粗细 | 细 / 正常 / 粗（随输入框宽度缩放） |
| 强度 | 柔和 / 正常 / 强烈 |
| 随 tok/s 变色 | 开关；运行中按 tok/s 改变边框颜色 |
| 色带 | 冷色（默认）/ 速度表 / 全光谱 / 蓝紫粉 |
| 速度上限 | 达到红色时的 tok/s，默认 100 |
| 阴影 | 开关、大小、浓度、跟随边框颜色、阴影颜色 |
| 颜色 | 运行中 / 等待 / 完成 / 出错，取色器选择 |
| 彩色 | 沿自定义色板循环 |
| 色环速度 | 慢 / 正常 / 快 |
| 色板预设 | 自定义 / 默认 / 霓虹 / 日落 / 冰蓝 / 森林 / 糖果 |
| 自定义色板 | 逗号分隔的 CSS 颜色 |

## 预览状态

想直接看某个状态的效果，在输入框执行：

```
/motion-preview waiting
/motion-preview done
/motion-preview error
```

也支持 `working` / `idle`。每个状态保持 5 秒，然后回到真实状态。

## 注意

- 仅支持 OpenCode 桌面版 / Web 窗口（GUI part），TUI 不显示。
- 需要 OpenCode 2.2 或更高版本。
- 插件通过 `contenteditable` 定位输入框容器，依赖宿主 DOM 结构；OpenCode 大版本升级后可能需要更新选择器。
- 关闭“阴影”后不会添加投影；呼吸光晕仍保留自带的轻微内发光。
- 启用期间会把输入框自带的 0.5px 边缘阴影画在内侧：平时可见，动画经过的角度会被遮掉。

## 版本

### 1.1.0（2026-11-23）

- 新增“随 tok/s 变色”：运行中边框颜色跟随输出速度。
- 四套色带：冷色（默认）、速度表、全光谱、蓝紫粉。
- 速度上限可配置，20–600 tok/s，默认 100。
- 对分块输出做平滑：保持上一次速度 2.5 秒，之后约 3 秒缓慢回落。
- 随 tok/s 变色改为从边框前缘向后缘渐变，不再整圈瞬间换色。
- 边框粗细会随输入框宽度略微缩放，大窗口下保持视觉比例。
- 流动效果改为旋转合成层，而不是每帧重绘渐变，动画更顺滑。
- 增加轻微边缘柔化，减少 1x 屏幕上的锯齿。
- 把输入框自带的 0.5px 边缘阴影移到内侧，动画经过的角度会被遮掉，其余位置仍然显示。
- 呼吸光晕改为持续循环，最低点保留较暗的边框，并自带轻微内发光。
- 霓虹闪烁改为持续循环。
- 设置页新增“恢复默认”按钮。
- 恢复按钮增加按压反馈，恢复后显示提示。
- 阴影分组移到设置页最后。
- 设置控件改为原生控件，修改后立即刷新。
- 修复旧默认色板导致“色板预设”显示为“自定义”。
