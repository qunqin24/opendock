# Magpie 模型测速

在 Magpie 的「模型测速」页面点「开始测速」，逐个测量当前网关启用的文本模型。每轮都要求抄写同一段英文，最多请求 256 个输出 token。同时呈现**端到端速度**与**正文流速**，支持搜索过滤、动态排序，以及把表格、JSON 和长图复制到剪贴板。测速会消耗模型额度。

```sh
magpie plugin add magpie-model-speedtest
```

本地开发可用 `magpie plugin add ./magpie-model-speedtest`。页面服务默认监听 `127.0.0.1:3487`，可在插件选项中修改 `port`。网关端口从 Magpie 的 `gateway.json` 读取，插件用调用方标识 `magpie-model-speedtest` 访问本机网关。无需另外配置供应商密钥。

- **端到端速度 (E2E Throughput)**：综合网络建连、排队、Prompt 预填充、内部思考（Reasoning）与正文输出的全局总耗时计算的 token/s，直观反映发出请求到完整拿到结果的真实体验。
- **正文流速 (Streaming Speed)**：排除首字等待与思考延迟，仅统计首个可见字符到达至最后一个字符到达之间的打字机喷发流速。
- **首字延迟 (TTFT)**：从发出请求到收到第一段可见正文的等待时间，支持智能色阶标注。
- 默认可测全部实体模型，也可自选多个；轮数可选 1、3 或 5。3 轮起按模型汇总 P50，并给出均值和 P95。
- 每一行都能单独重测。失败行可查看请求参数、错误和响应片段。
- 自动总结最快端到端、最低首字、最快打字机，以及打字速度和首字各占一半的综合第一。
- 散点图以首字延迟为横轴、正文流速为纵轴。指针停在点上会显示模型名称。
- 支持按名称过滤。表格、原始 JSON 和长图都复制到剪贴板，不在 Magpie 窗口里下载文件。
- 供应商同时报告输出和推理用量时，以两者之差作为正文 token 数。缺少推理明细时，按英文正文平均 4 个 UTF-8 字节估算一个 token。
- 正文集中在 10 毫秒以内到达或整段返回时，端到端速度正常计算，正文流速留空。只有推理、流中断、HTTP 错误和单请求超过 60 秒都会逐行标明，队列继续。支持时使用模型公开的最低推理档位。
- 停止会取消当前请求和后续队列。已完成的结果在本次服务进程内保留到下次测速。
